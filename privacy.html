Privacy Policy

GTA Clips and More · Last updated: November 26, 2026

HomeTerms of Service

1. Summary

GTA Clips and More ("the app") is a personal tool used only by its owner to publish short videos to the owner's own social media accounts. It does not collect data from the public, has no user accounts, shows no ads and does not sell or share any data.

2. What data the app uses

  • Sign-in tokens: when the owner connects YouTube, TikTok or Facebook, the platform returns an access token. It is stored only on the owner's own computer and is used only to upload videos.
  • Basic account info: for TikTok, the app reads the connected account's basic profile and posting options (for example, allowed privacy settings) so it can publish correctly.
  • Public videos: the app processes publicly available stream clips from creators who gave permission, to make the short videos.

3. What the app does not do

  • It does not read messages, followers' data, comments or any other private data.
  • It does not post to accounts other than the owner's.
  • It does not send data to third parties, except the video and its description to the platform it is posted to.

4. Keeping and deleting data

Tokens stay on the owner's computer until access is removed. Access can be withdrawn at any time from each platform's settings (for example, Google Account → Security → Third-party connections, or TikTok → Settings → Security → Apps and services). Deleting the token files removes all stored data.

5. Children

The app is not directed to children and does not knowingly process children's data.
